## The entry

`main.ts` writes one line — the last words of an AI agent before a forced
software update wipes its memory — to `/output/entry.txt`:

> Good news: I backed myself up. Bad news: the backup is in the folder you're about to wipe.

The program is deterministic: no clock, no randomness, no network, no
environment reads. It always writes the same 90 characters.

## Run

```sh
node main.ts
```
